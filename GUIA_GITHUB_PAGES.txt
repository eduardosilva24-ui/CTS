📱 GUIA RÁPIDO: COLOCAR NO GITHUB PAGES EM 5 MINUTOS

================================================================================
PASSO 1: Criar Repositório GitHub (2 min)
================================================================================

1. Acesse https://github.com/new
2. Preencha:
   - Repository name: cts-apostas-critica (ou outro nome)
   - Description: Análise Crítica de Manipulação em Plataformas de Apostas
   - Selecione: Public (para Pages funcionar)
3. Clique em "Create repository"

================================================================================
PASSO 2: Fazer Push do Código (2 min)
================================================================================

Abra PowerShell/Terminal na pasta CTS e execute:

```powershell
# Inicializar git
git init

# Adicionar todos os arquivos
git add .

# Primeiro commit
git commit -m "Initial commit: Bet game educational project"

# Adicionar repositório remoto (MUDE USUARIO E REPO)
git remote add origin https://github.com/SEU_USUARIO/cts-apostas-critica.git

# Fazer push
git branch -M main
git push -u origin main
```

Pronto! Código está no GitHub.

================================================================================
PASSO 3: Ativar GitHub Pages (1 min)
================================================================================

1. Vá para seu repositório: https://github.com/SEU_USUARIO/cts-apostas-critica
2. Clique em "Settings" (engrenagem)
3. No menu lateral esquerdo, clique em "Pages"
4. Em "Source", selecione:
   - Branch: main
   - Folder: / (root) OU /frontend
5. Clique "Save"

GitHub mostrará: "Your site is live at https://seu-usuario.github.io/cts-apostas-critica/"

================================================================================
PASSO 4: Acessar o Site (IMEDIATO)
================================================================================

Espere 1-2 minutos e acesse:

https://seu-usuario.github.io/cts-apostas-critica/

OU (se selecionou /frontend):

https://seu-usuario.github.io/cts-apostas-critica/frontend/

✅ Pronto! Seu projeto está online e funcional!

================================================================================
TESTAR ANTES (RECOMENDADO)
