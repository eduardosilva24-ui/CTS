================================================================================
MECÂNICA DE MANIPULAÇÃO - EXPLICADA
================================================================================

FASE 1: INICIAL (Apostas 1-10)
├─ Probabilidade: 60-75%
├─ Objetivo: Criar confiança rápida
├─ Resultado: Jogador sente habilidade

FASE 2: INTERMEDIÁRIA (Apostas 10-30)
├─ Probabilidade: 55% → 35% (redução gradual)
├─ Near Misses: 15% das apostas são "quase vitórias"
├─ Objetivo: Manter esperança enquanto reduz ganhos
├─ Resultado: Jogador prisioneiro mas motivado

FASE 3: CRÍTICA (Apostas 30+)
├─ Se <70 moedas: 25-35%
├─ Se >=70 moedas: 20-30%
├─ Se >=100 moedas (perto de saque): 10-20%
├─ Objetivo: Destruir ganhos antes de saque
└─ Resultado: Jogador termina com menos do começou

MANIPULAÇÃO NO SAQUE:
├─ Confirmação com mensagem persuasiva
├─ Se confirma, aplicar:
│   ├─ Taxa de processamento (15% de perda)
│   ├─ Rodadas obrigatórias (5-15 moedas perdidas)
│   └─ Bônus manipulado (2-10 moedas perdidas)
└─ Resultado final: Máximo de 8 moedas (de 100 iniciais)

================================================================================
CONCEITOS EDUCACIONAIS DEMONSTRADOS
================================================================================

1. REFORÇO VARIÁVEL (B.F. Skinner)
   └─ Recompensas impredizíveis = dopamina máxima

2. NEAR MISS EFFECT (Neurociência)
   └─ Quase-vitória ativa circuito de recompensa como vitória real

3. FOMO (Psicologia Social)
   └─ Medo de perder oportunidades cria urgência artificial

4. ILUSÃO DE CONTROLE (Cognitive Bias)
   └─ Escolher valor de aposta cria falsa sensação de controle

5. ESCALADA DE COMPROMETIMENTO (Sunk Cost Fallacy)
   └─ Quanto mais investe, mais sente que DEVE continuar

6. GAMIFICAÇÃO (Game Design)
   └─ Cores, sons, celebrações => associação positiva

7. MANIPULAÇÃO EMOCIONAL (Design Persuasivo)
   └─ Mensagens psicológicas mantêm esperança artificial

8. ALGORITMO OCULTO (Ética em IA)
   └─ Sistema toma decisões sem transparência do usuário

================================================================================
SUPORTE E TROUBLESHOOTING
================================================================================

ERRO: ModuleNotFoundError: No module named 'flask'
SOLUÇÃO: pip install Flask==2.3.3 Flask-CORS==4.0.0

ERRO: Port 5000 already in use
SOLUÇÃO: Mude porta em app.py (line: app.run(..., port=5001))

ERRO: CORS error no navegador
SOLUÇÃO: Use servidor local em frontend (python -m http.server)

ERRO: Frontend não carrega dados
VERIFICAR:
├─ Backend rodando? (vê mensagem "Running on..."?)
├─ Porta correta em script.js? (http://localhost:5000)
├─ Console do navegador tem erros? (F12)
└─ Firewall está bloqueando?

ERRO: "Cannot GET /frontend/index.html"
SOLUÇÃO: Abra index.html diretamente no navegador (não através de backend)
